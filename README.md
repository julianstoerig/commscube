# commscube
a simple mesh radio using text over LoRa

# Struktur

- `dokumente/` Typst-Dateien mit PDFs, Bilder unter `bilder/`
- `firmware/` ESP32-Firmware

Kompiliert wird in `dokumente/`, etwa mit `typst compile folien.typ`.
